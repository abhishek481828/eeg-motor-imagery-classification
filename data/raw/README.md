# Raw EEG Data Directory

This directory is designated for storing raw PhysioNet EDF files downloaded from PhysioNet.

> [!WARNING]
> Raw EDF files contain biometric physiological data and large binary arrays. **Raw EDF files must never be committed to Git.**

Follow the download instructions in the root [`README.md`](../../README.md#11-dataset-download-instructions) to populate `data/raw/physionet/`.
